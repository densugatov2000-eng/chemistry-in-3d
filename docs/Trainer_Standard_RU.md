# Стандарт нового тренажёра «Химия в 3D»

## Файлы

Создайте `simulator/<slug>/` и используйте в имени папки строчные латинские буквы, цифры и одиночные дефисы между группами символов. Пример имени — `electron-shells`.

| Файл | Требование |
| --- | --- |
| `index.html` | Самостоятельное приложение. Локальные ресурсы подключаются относительными путями. |
| `manifest.json` | Паспорт карточки. Скопируйте `manifest.template.json` и заполните его фактическими данными. |
| `preview.webp` | Превью карточки. Используйте снимок реальной модели, рекомендуемый размер 960×540. |
| `social-preview.png` | Изображение Open Graph. Рекомендуемый размер 1200×630. |

При необходимости добавьте папки `assets/`, `js/`, `css/` и `data/`. Сборка переносит из них статические ресурсы с поддерживаемыми расширениями и сохраняет вложенные пути. Разрешённые расширения перечислены в `PUBLIC_EXTENSIONS` в генераторе. Храните тесты, отчёты, черновые выгрузки и резервные копии вне этих папок. Прямые ссылки файловой системы и символические ссылки в поставке запрещены.

## Паспорт

Укажите постоянный `id` и уникальный положительный целый `number`. Два тренажёра, включая черновики, не могут делить идентификатор или номер. Заполните название, полное описание, тематический раздел и `imageAlt`. Укажите ОГЭ и/или ЕГЭ в `exams`, функции в `features`, показатели в `metrics`, ключевые слова в `keywords`. Если показателей или функций нет, оставьте соответствующий массив пустым.

Переключайте `status` между `draft`, `planned` и `published`. Для всех статусов требуются валидный паспорт и четыре файла. Черновики проверяются, но не включаются в сайт Pages. Поля `slug`, `url` и `image` вычисляются сборкой из имени папки.

## Навигация и данные

- Добавьте общую шапку «Химия в 3D» и ссылку «← Все тренажёры» с `href="../../"`.
- Для общей иконки используйте `../../favicon.svg`.
- Укажите абсолютные значения canonical и Open Graph для пути `https://densugatov2000-eng.github.io/chemistry-in-3d/simulator/<slug>/`. Параметр `og:image` должен указывать на `social-preview.png` по тому же пути.
- Используйте для прогресса собственный ключ `chemistry3d:<trainer-id>:<schema-version>`. Папки одного домена делят браузерное хранилище. Сохраняйте совместимость при обновлении формата данных и не очищайте хранилище целиком.
- Прогоните локальную сборку и проверьте прямой адрес, переход в каталог, работу с мобильного экрана и загрузку всех ресурсов. Когда тренажёр готов, измените статус на `published` и отправьте папку в `main`.
